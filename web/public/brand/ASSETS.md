# Learn DeepInfer 品牌素材

- logo.png：1024×1024 透明底单色图标。
- logo-32.png / logo-192.png / logo-512.png：网页与图标尺寸。
- org-avatar.png：1024×1024 暖白底头像，可用于 GitHub 组织。
- apple-touch-icon.png：180×180 Apple 触屏图标。
- favicon.ico：包含 16、32、48 像素图标。
- inference-lab.webp：1440×1080 首页插画，属于抽象品牌视觉。
- social-cover.jpg：1200×630 网站分享封面。

颜色：森林绿 #19654e、深墨绿 #202d29、暖白 #f5f4ef。

Logo 和插画通过用户指定的 aigc-image-generator 生成。透明底整理、尺寸处理与分享封面排版在本地完成。完整提示词与任务 ID 见 generation-record.json 和两个 prompt.txt 文件。
