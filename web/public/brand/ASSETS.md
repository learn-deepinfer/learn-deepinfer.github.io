# Learn DeepInfer 品牌素材

- logo.png：1024×1024 透明底单色图标。
- logo-32.png / logo-192.png / logo-512.png：网页与图标尺寸。
- org-avatar.png：1024×1024 暖白底头像，标志保留圆形裁切安全区，用于 GitHub 组织。
- apple-touch-icon.png：180×180 Apple 触屏图标。
- favicon.ico：包含 16、32、48 像素图标。
- inference-lab.webp：1440×1080 首页插画，属于抽象品牌视觉。
- social-cover.jpg：1200×630 网站分享封面。

颜色：森林绿 #19654e、深墨绿 #202d29、暖白 #f5f4ef。

Logo 和插画通过用户指定的 [aigc-image-generator](https://github.com/liangqianxing/aigc-image-generator) 生成。新 Logo 以层叠几何形状暗示 D 与请求流转，沿用森林绿。

透明底整理、尺寸处理与分享封面排版在本地完成。完整提示词与任务 ID 见 generation-record.json 和两个 prompt.txt 文件。原始 Logo 与生成响应保存在 docs/brand-generation/2026-10-20/，图标处理脚本为 docs/brand-generation/prepare-logo.py。分享封面从 docs/diagrams/social.html 渲染，双语 README 封面从 docs/diagrams/hero.html 渲染。
